# Acceptance Criteria — Phase 00

The Phase 00 task is complete only when:

- [ ] The app installs from a clean checkout with `npm install`.
- [ ] `npm test` passes.
- [ ] `npm run build` passes.
- [ ] The app can be started with the documented command.
- [ ] The page clearly identifies StepByte Studio and the Overnight Lab.
- [ ] Layout remains usable on narrow/mobile and desktop widths.
- [ ] No production system, credential, paid service, or external publication is used.
- [ ] Browser/visual verification is performed when tooling is available; otherwise the limitation is documented.
- [ ] `reports/OVERNIGHT_REPORT.md` contains the work summary, tests, defects found/fixed, unresolved issues, and human review items.
